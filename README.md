# Breast Cancer Classification

## Описание проекта

Проект посвящён решению задачи бинарной классификации опухолей молочной железы на основе характеристик клеточных ядер.

Цель проекта — исследовать данные, выполнить предобработку, обучить несколько моделей машинного обучения, сравнить их качество и подобрать оптимальные гиперпараметры.

Целевая переменная:
- `B` — доброкачественная опухоль;
- `M` — злокачественная опухоль.

## Датасет

Используется датасет [Breast Cancer Wisconsin (Diagnostic)](https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data).

Основные характеристики:
- 569 наблюдений;
- 30 числовых признаков;
- 1 целевая переменная `diagnosis`;
- 357 доброкачественных наблюдений;
- 212 злокачественных наблюдений.

Идентификатор записи и пустой столбец `Unnamed: 32` были удалены перед анализом.

## Исследовательский анализ данных (EDA)

В ходе анализа были выполнены:
- изучение структуры и типов данных;
- проверка пропущенных значений;
- анализ распределения целевой переменной;
- исследование распределений числовых признаков;
- построение корреляционной матрицы.

Была обнаружена высокая корреляция между рядом признаков, особенно между характеристиками размера опухоли.

## Предобработка данных

В процессе подготовки данных:
- целевая переменная была отделена от признаков;
- данные разделены на обучающую и тестовую выборки с использованием `train_test_split`;
- применён параметр `stratify` для сохранения пропорций классов;
- для отбора признаков использован `SelectKBest` с функцией оценки `f_classif`;
- для Logistic Regression и SVC применялся `StandardScaler`;
- этапы предобработки и обучения объединены с помощью `Pipeline`.

В итоговом эксперименте использовалось 20 признаков.

## Использованные модели

Для решения задачи были выбраны три алгоритма:
- Logistic Regression;
- Support Vector Classifier (SVC);
- Random Forest Classifier.

Для оценки устойчивости моделей использовалась стратифицированная кросс-валидация `StratifiedKFold` с пятью разбиениями.

## Подбор гиперпараметров

Для автоматического подбора гиперпараметров использовалась библиотека Optuna.

Для каждой модели создавалось отдельное исследование. В качестве целевой метрики оптимизации использовался F1-score для положительного класса `M`.

### Результаты кросс-валидации до оптимизации

| Модель | Средний F1-score | Стандартное отклонение |
|---|---:|---:|
| Logistic Regression | 0.957 | 0.019 |
| SVC | 0.952 | 0.024 |
| Random Forest | 0.944 | 0.030 |

### Лучшие результаты Optuna

| Модель | Лучший средний F1-score |
|---|---:|
| Logistic Regression | 0.9641 |
| SVC | 0.9699 |
| Random Forest | 0.9474 |

После оптимизации наилучший средний результат кросс-валидации показала модель SVC.

## Финальная оценка моделей

После подбора гиперпараметров модели были обучены на обучающей выборке и проверены на тестовой выборке.

Для оценки использовались:
- Accuracy — доля правильных предсказаний;
- Precision — точность положительных предсказаний;
- Recall — полнота обнаружения положительного класса;
- F1-score — гармоническое среднее Precision и Recall.

Положительным классом считался `M` — злокачественная опухоль.

| Модель | Accuracy | Precision (M) | Recall (M) | F1-score (M) |
|---|---:|---:|---:|---:|
| Logistic Regression | 99.12% | 100.00% | 97.62% | 98.80% |
| SVC | 98.25% | 97.62% | 97.62% | 97.62% |
| Random Forest | 97.37% | 100.00% | 92.86% | 96.30% |

### Анализ результатов

На тестовой выборке наилучший результат показала Logistic Regression:
- Accuracy — 99.12%;
- Precision — 100%;
- Recall — 97.62%;
- F1-score — 98.80%.

SVC показала лучший результат по средней оценке F1-score во время кросс-валидации после оптимизации гиперпараметров — 0.9699.

Различие между результатами кросс-валидации и тестирования возможно, поскольку модели оцениваются на разных разбиениях данных.
